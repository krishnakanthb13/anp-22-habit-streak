   - Recurrence: Custom N-day cadence, weekly alignment, monthly anchor clamping, leap year edge cases.
   - Error & defensive handling: Null/undefined habit safety, malformed date string sanitization, out-of-bounds parameters.

2. **`test/store.test.js`** (15 tests)
   - Schema normalization: Partial habit normalization, active habit fallback, markdown JSON fencing.

3. **`test/features.test.js`** (18 tests)

### Key Protections Verified
- **Zero Data Loss on Note Corruption**: `mutateState` explicitly rejects mutations if the stored data note contains invalid/corrupted JSON.
- **Cross-Runtime Concurrency Guard**: `saveState` compares persisted note revisions before writing to prevent multi-device lost updates.
- **Recurrence Schedule Integrity**: Actions on off-schedule days are blocked server-side and hidden in the dashboard UI.
- **Audit & Calendar Consistency**: Undo only removes actual check-in action events, preserving manual calendar adjustments.
