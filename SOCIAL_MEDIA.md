# Social Media Announcements: Habit Streaks Plugin

## Released: Habit Streaks v0.0.3

### LinkedIn
Excited to announce the open-source release of Habit Streaks (v0.0.3) for Amplenote! 🚀

Most habit tracking tools enforce a one-size-fits-all model: start every day at zero and tap a button to check it off. But if your goal is sobriety or breaking a bad habit (like quitting smoking or alcohol), you're already winning just by living your day.

Habit Streaks introduces a Quitly-inspired dual philosophy to Amplenote:
• 🛡️ Abstinence / Quitting Mode: Passive count-up with live ticking clocks (Days, Hours, Minutes, Seconds). You only check in if a setback occurs, with reflection notes.
• 🎯 Positive Action Mode: Intentional daily check-in with support for multiple sessions per day and 7-day repeatingness bar charts.
• 🌿 Laurel Milestone Tiers: Progressive goals from 1 Day to 5 Years with dynamic progress bars.
• 📅 Interactive Monthly Dot Calendar: Instant 0ms client-side month navigation and click-to-toggle days.
• ⚡ Zero-Lag Architecture: In-memory client rendering with isolated JSON note persistence.

Check out the open-source project and documentation here:

I wanted to share a plugin I built for Amplenote called **Habit Streaks** (v0.0.3).

### The Motivation
Most habit trackers force you to tap a button every day. That works great for going to the gym, but it completely falls apart for abstinence goals (e.g. *No Alcohol*, *No Smoking*, *No Junk Food*). With quitting goals, you are succeeding by default; you only need to interact when you experience a slip.

### What it does
1. **Dual Philosophy Engine**:
   - **Abstinence / Quitting Mode**: Automatic continuous count-up.
   - **Positive Action Mode**: Daily check-in tracking with multiple logs per day.
2. **Live Digital Ticker**: Live counting of Days, Hours, Minutes, and Seconds.
3. **Quitly Laurel Tiers**: Progressive unlockable milestone badges from 1 Day to 5 Years.
4. **7-Day Repeatingness Bar Chart**: Visualizes daily action frequency over the past week.
5. **Interactive Monthly Dot Calendar**: Horizontal month navigation with 0ms delay.
6. **Reflection Log**: When resetting a counter, you can attach a reflection note to learn from setbacks.
7. **Zero-Lag Embed**: Everything renders in-memory inside the iframe, persisting to a JSON code block in an authoritative note.

The project is completely open source under GPL-3.0.
